# Rolewise

Rolewise is a truthful AI job-search workspace for developers. It brings role discovery, fit scoring, tailored application materials, application tracking, and interview preparation into one focused workflow.

The product name is configurable with `NEXT_PUBLIC_APP_NAME`.

## Repository layout

- `frontend/` — Next.js App Router application
- `backend/` — FastAPI API and domain services
- `docker-compose.yml` — local PostgreSQL, Redis, API, and web stack

Detailed local setup, testing, AI provider, and deployment guidance will be completed with the production hardening increment.
